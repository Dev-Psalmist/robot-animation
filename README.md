# Robot Animation — Prosthetics Hero

A responsive, single-page prosthetics hero built with **React, TypeScript, Vite and Tailwind CSS**.

## Stack
- React + React DOM
- TypeScript
- Vite
- Tailwind CSS
- lucide-react (available as the permitted icon package)

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

The page intentionally contains only the requested hero experience. There is no backend, database, Supabase integration, routing, or additional content sections because none was specified in the brief.
